# 数据库目录

新环境空库先使用 `00-release/000-schema.sql`，再使用 `00-release/001-seed.sql`。种子不附带真实人员、管理员密码或本机业务数据。

其他编号目录记录各阶段增量结构与初始化SQL，仅适用于相应旧版本。不要将所有SQL对现有库按文件名盲目重放；先核对当前结构、约束与已执行版本，备份后选择迁移。

当前成员只有READER、EMPLOYEE；管理员通过ADMIN角色表达，旧AI成员与旧档案表已退役。`16-retire-ai-member` 的SQL是带空表前置检查的结构收尾，非自动清库脚本；已有数据必须先独立备份、盘点关联并受控迁移。

逻辑关系由Service与索引维护，不依赖外键。当前权威结构以新装DDL与Java测试结构为准，功能与流程见 [项目设计](../docx/project/system-design.md)。
