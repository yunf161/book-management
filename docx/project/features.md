# 功能清单

## 用户与权限边界

成员类型只有读者（READER）、员工（EMPLOYEE）；管理员与馆员都使用员工资料，由不同角色授权。一个成员关联一个角色，权限定义与数据范围通过角色权限表关联。界面是否显示按钮不能替代服务端鉴权。

| 模块 | 读者/本人 | 馆员/管理员 | 状态与边界 |
| --- | --- | --- | --- |
| 认证 | 邮箱登录、验证码注册、重置密码、退出 | 同一认证链 | JWT与Redis会话；邮件需自行配置 |
| 个人资料 | 普通资料、兴趣和偏好维护 | 授权字段维护 | 账号、额度、资格与任职信息按专项权限或审批维护 |
| 资料申请 | 资格、恢复资格、额度和适用的状态变更申请 | 按角色/申请类型审批 | 七天到期转EXPIRED并解除待审批重复限制 |
| 人员管理 | 查看自身授权资料 | 读者/员工聚合查询、受限维护、账号停用 | 普通人员CRUD不开放管理员账号直接增删改 |
| 部门 | 无通用管理权 | 查询、新增、修改/停用、删除无引用部门 | 编码名称唯一，员工引用检查 |
| 权限定义 | 本人有效权限查询 | 定义的分页、创建、更新、删除 | 编码不可改；被角色引用时不能删除；无完整角色授权管理页面 |
| 政策 | 查询当前政策，显式接受/拒绝须知 | 草稿、版本列表、发布、生效指针 | 准入和借阅政策；旧会话受最新须知约束 |
| 分类 | 公开聚合检索 | 分类层级维护、停用 | 父子循环检查、同级重名检查 |
| 书目 | 组合检索、分类路径、库存、封面 | 出版版本维护、停用 | 书目与实体副本分离；下架和历史引用保留 |
| 副本 | 库存体现在书目上 | 条码、位置、书况及状态维护 | 普通维护不能替代借出/归还状态转换 |
| OSS封面 | 查询可访问图片地址 | 上传、更换、删除 | 大小/类型/对象归属核验；仅封面，不是通用文件中心 |
| 借阅申请 | 提交、查询本人申请、取消待办 | 聚合查询、批准/拒绝 | 重复申请、资格、规则、额度与库存校验 |
| 续借 | 关联现有借阅记录提交申请 | 与借阅申请统一审批 | 次数上限与政策校验；不增加借阅数量、不更换副本 |
| 归还 | 查询本人记录与结果 | 按记录或条码办理 | 正常归还、损坏、遗失；防重复扣减额度 |
| 逾期 | 查看逾期状态/天数 | 查询、定时同步 | 不足一天按一天；不包含罚款与支付 |
| 额度 | 查看长期与临时有效额度，提交申请 | 审批或专项授权维护 | 临时额度是总上限，不是增量；到期恢复长期额度 |
| 阅读计划 | 计划、条目、进度与顺序维护 | 按授权范围管理 | 目标指完成书目数，不限制书单容量；完成状态需满足约束 |
| 推荐 | 当前六本以内推荐、刷新、反馈、兴趣选择 | 馆藏标签支持 | 个性化规则排序/AI候选内重排；关闭个性化时热门排序 |
| 推荐保留 | 不开放历史批次查询 | 无面向用户的历史入口 | 至多两个历史批次、六条历史反馈，生成时轮替 |
| 消息 | 联系馆员、会话、消息查询/已读 | 私聊、多收件人消息、会话管理 | 数据库落地，离线可补查；WebSocket只是实时通道 |
| 咨询AI | 日常交流、咨询、多轮、来源和流式回答 | 相同入口加授权工具 | 阿里云优先，Ollama降级；实时数据通过Java只读工具 |
| 业务AI | 根据Skill生成操作提案，确认/取消 | 根据当前权限办理相应业务 | 不依赖AI成员账号；模型不能自行授予权限 |
| AI任务 | 查询、取消、有限重试和用量 | 授权核对UNKNOWN结果、查看能力状态 | 有界任务执行，不宣称完整分布式任务平台 |
| 知识库 | 回答中引用可用资料 | 导入、编辑、MD5去重、搜索、重建及进度 | TXT/MD/CSV/JSON/文本PDF；无OCR承诺 |
| AI治理 | 人工接管申请、摘要确认 | 接管、会话、结束；能力开关 | GLOBAL/CONSULTATION/BUSINESS/RECOMMENDATION联动执行链 |
| 运营 | 无默认运营权限 | 时间范围统计、图表、Excel模板/导入/导出/结果下载 | 分行结果、错误报告和授权文件下载 |
| 审计 | 无全系统审计查询权 | 脱敏操作记录、组合查询 | 不记录明文密码、JWT和API Key等敏感内容 |

## 当前不提供

- AI成员账号和独立AI人员CRUD；旧类型仅保留拒绝历史访问的兼容代码。
- 独立预约、罚款/支付、活动、备书、多角色、用户单独授权和完整角色授权管理前端。
- 主动推荐订阅推送、动态阅读重规划、AI自主资格审批或自主调额。
- 通用私有文件管理、扫描PDF OCR、跨节点AI任务无损迁移。
- 停用账号免登录自助恢复：当前停用后不能登录，应由授权管理员恢复，不能把申请类型的存在等同于该闭环已贯通。

以上清单不表示每项功能适用于任意馆员。实际可操作范围由权限编码、数据范围、本人关系和记录状态共同决定。
