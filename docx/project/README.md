这是面向代码评审、远程仓库和简历展示的当前文档集，基线日期为2026-10-21。本目录只收录当前交付说明，历史开发与临时调试资料不随本版本发布。

2. [系统设计](system-design.md)：架构、表关系、事务边界与关键流程。

3. [技术设计清单](technical-design.md)：每项技术的实际用途、源码入口和限制。

5. [运行与验证](runbook.md)：依赖、初始化、启动与测试。
6. [人工演示主线](demo.md)：使用自己的演示账号串联真实业务。
7. [简历与面试材料](resume.md)：可直接改写的项目描述与技术追问。

9. [本次源码验证记录](verification.md)：干净目录的测试结果、修复与历史计数差异。

文档中的状态分为：已实现、外部配置后可用、当前不提供。自动生成接口清单反映Spring注册项，不代替Service中的业务约束，也不等同于全场景验收。

公开源码包不带本机数据库、账号密码、用户文档、模型权重、向量索引、联调录屏或旧Git历史。测试数字仅反映记录中的运行结果，不代表生产SLA。
